# 能不能做到「每笔稳定 +0.05×share，同时避免 −0.95×share 的损失」？

> 目标（用户）：不赚"便宜的钱"（0.55 成交=大风险），要**每笔稳定赚 0.05×share**，同时**避免 0.95×share 的损失**。
> 数据：44.9 天 / 12,024 窗口 / 1,039,610 行；样本 = `fav_ask` 首触 ∈[0.95,0.96] 的窗口（7326/9121 笔）
> 复现：`python3 scripts/b0_payoff_reshaper.py 120 5`（秒窗口）/ `... 300 5`（无时间窗）

---

## 结论

| 你的两个要求 | 能否做到 | 依据 |
|---|---|---|
| **每笔赚 0.05/share** | **只能做到 60–67% 的笔数** | 无止损时净赚 ≥5c/股 的占比：**60.2%**（sec≤120）/ **67.2%**（sec≤300）。"每笔"=100% 胜率，做不到。 |
| **避免 −0.95/share 的损失** | **做不到** | **11 个止损位下，最差单笔恒为 −96.3c/股**（价格跳空，中间没有可出的价位）。且止损让均/股从 **−0.06c 恶化到 −0.20 ~ −1.29c**。 |

---

## 1. 算术约束：亏损上限 L 决定所需胜率

买入价 p（=0.95），赢赚 `1−p` = 0.05/股，单笔亏损上限 `L` ⇒ 打平所需胜率

> **W\* = L / (L + 0.05)**

| 亏损上限 L（每股） | 所需胜率 W\* |
|---|---|
| **0.95（现状：持有到结算）** | **95.0%** |
| 0.50 | 90.9% |
| 0.20 | 80.0% |
| 0.10 | **66.7%** |
| **0.05** | **50.0%** |

门槛确实随 L 下降而降低。**但止损在压低 L 的同时，会把实际胜率压得更低**——下面就是这条赛跑的实测。

**三条硬结论：**

1. **最差单笔恒为 −96.3c/股，止损位再紧也一样。** 原因是**跳空**：价格可以从 0.94 一步到 0.55、再到 0.30、再到 0 —— 昨夜那笔就是活例子（0.94 → 0.55 → 0.30 → 0，全程约 15 秒，中间没有任何一个你来得及挂出卖单的价位）。
   > **止损能限制"慢慢跌"的亏损，完全无法限制"跳空"的亏损。而后者正是 4.4% 那批。**

2. **止损让整体更差，且越紧越差。** 均/股 −0.06c → −0.20c（s=0.50）→ −1.29c（s=0.94），单调恶化。

3. **止损会"滑穿"。** 想在 0.94 止损，第一笔满足 `bid ≤ 0.94` 的采样点价格平均约 **0.913**（滑穿 3.5 分）。所以实际 L 从 2 分变成 ~5 分，**正好把需要胜率从 29% 推到 50%，而实际只有 43.9%**。

4. **`≤−10c` 的笔数反而变多**：4.4% → 6.0% ~ 19.1%。止损把一批本该赢到 1.00 的仓位变成中等亏损。

> sec≤300 口径完全一致（基线均/股 −0.10c；止损 −0.36c ~ −1.53c；最差恒为 −96.3c）。

## 3. 为什么必然如此：出场价是鞅

市场价格 = 概率（路径校准：当仓位跌到 L 时，其真实胜率≈L）。其等价表述是：

> **对任何出场规则（止损位、时间止损、任意函数），`E[出场价] = 入场价`。**

所以**任何出场规则都无法创造期望，只能在"胜率 × 赢面"和"负率 × 亏面"之间搬来搬去**。
"每笔 +0.05 且避免 −0.95"要求 `E > 0` —— 那只可能来自**入场折价**，不可能来自出场。

## 4. 那"稳定"从哪来？只有两个真实来源

### 来源 A：入场折价（唯一数学上站得住的）

0.95 处的实测：`bid 0.940 / mid 0.945 / ask 0.950`，真实胜率 **96.41%**，即 `w − mid = +1.91pp`。

| 执行路线 | 成交价 | 净 EV/股 | 5 股/笔 |
|---|---|---|---|
| 吃 ask（现状） | 0.950 | +1.07c | +$0.054 |
| 买在 mid（不可成交） | 0.945 | +1.55c | +$0.078 |
| **挂 bid（maker，含返佣）** | **0.940** | **+2.49c** | **+$0.125** |

⇒ **把入场从 ask 换成 maker，正是你要的"每笔 +0.05/share"**（+$0.054 → +$0.125/笔）。
**但它换不掉尾部**：做 maker 同样持有到结算，输的时候一样是 −0.95/share。

### 来源 B：降低单笔敞口（你明确不想要的"便宜钱"的反面）

你的"不需要赚便宜的钱"这个判断**在仓位管理上是对的**，而且已经落地：**按股数下单**（`takerBuyByShares`）让崩盘成交时亏 `5 × 成交价` 而不是固定 $4.80 —— 昨夜那笔从 −$4.80 降到 **−$2.75**。

## 5. 关于"每笔 +0.05 且避免 −0.95"的直白结论

**这个目标不是"调参没调好"，而是与「在 0.95 买入并持有到结算」这个结构不相容。**

在 0.95 买并持有 = **卖保险**：95.6% 收 5c/股，4.4% 赔 96c/股。
你要的形状（+0.05 高频、尾部极小）恰好是**买保险**那一侧。而在二元市场里"买保险"就是**买便宜的腿**——那条路本项目已用 44.9 天数据大规模证伪（低价腿 EV 为负，被 0.5c 点差与手续费吃光）。

**所以真正的选择只有两个：**

| 选项 | 内容 |
|---|---|
| **A. 接受形状，把入场做便宜** | 0.95 处改 **maker 入场**（+1.4c/股）+ **上限 0.95**（+0.4c）+ **按股数**（尾部 $2.75 而非 $4.80）。期望 ≈ **+0.05/笔**，胜率 ~95%，**4.4% 概率仍亏 ~$4.75**。 |
| **B. 换收益形状族** | 承认自己要的是"小亏多次 + 偶尔大赚"，那就该买便宜的腿——**但这条路已被证伪**，所以实际等于**不做这个策略**。 |

**没有第三条路。** 在公平定价的二元市场里，"高胜率 + 尾部受控 + 正期望"三者不可兼得：**高胜率与尾部受控互为代价，正期望只能从入场折价来。**
