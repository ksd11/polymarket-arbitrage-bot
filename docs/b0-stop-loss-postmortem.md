## 0. 一句话

> **止损能改变出场价，但改变不了期望——它把决定权交给了 bid，于是你在"该走"时拿 0.354，"不该走"时也要走。**
> 实盘 3 次止损全部砍在最终会赢的腿上；44.9 天历史反事实里止损让总盈亏从 **−$47 恶化到 −$156**。

## 3. 成本核心：**滑穿 14.6 分**

你只能决定**触发线**；成交价由 **bid** 决定。

| 止损实际成交价 | 均值 | 中位 | p10 | p25 | p75 | p90 |
|---|---|---|---|---|---|---|
| | **0.354** | 0.390 | 0.140 | 0.250 | 0.400 | 0.490 |

**相对触发线 0.50，平均滑穿 14.6 分**（因为从"判定"到"能成交"之间价格还在掉）。

### 每股算钱（卖出价 vs 持有到结算）

| 分支 | 占比 | 卖出价均值 | 对照 | **每股** |
|---|---|---|---|---|
| 误杀 | 37.6% | 0.395 | 本可拿 1.000 | **−0.605** |
| 得救 | 62.4% | 0.328 | 本可得 0.000 | **+0.328** |
| **加权每触发一次** | | | | **−0.0228 元/股** |

> **打平所需误杀率 = 35.2%，实际 37.6%。** 结构上就站在亏损一侧：
> **"省下的"是残缺的（+0.328），"赔掉的"是完整的（−0.605）** —— 数量上的多数（62.4% 得救）救不回质量上的不对称。

（估算：−0.0228 × 5.05 股 × 627 次 ≈ **−$72**；总差 −$109 中其余部分是双边手续费。）

## 4. 为什么必然如此（三条机制）

1. **止损是"穿价卖出"**：它不是"在 0.50 卖出"，而是"在跌到 0.50 时向市场要一个价"。谁给你价由 bid 决定，所以恒定被打 10–15 分折扣。这与 4.9 天前 `stop_calibration.py` 的路径校准完全一致：**价格 = 概率，在 L 卖出与持有到结算期望相同**，止损只多付摩擦。

2. **它唯一真正想防的东西，它防不住。**
   你最初要防的是 `0.95 → 0.01` 的**一步跳空**（10:01 轮那笔 −$4.80）。那类事件里**根本没有你来得及挂出卖单的价位**——止损天然无效。
   它能起作用的只有"慢慢跌"那一类，而那一类在 0.50 附近真实胜率仍有约 50%，**卖掉它是 EV 中性偏负**。

3. **回撤下降是唯一的真好处**（引擎：$136.42 → $101.35，−26%），
   但那是**用期望换方差**——你付出 −0.236c/股，买到的是账面更平。若目标是"赚更多"，这笔交易不划算。

## 6. 边界与诚实声明

- **实盘样本很小**：3 次止损 3 次误杀，看起来极端。历史基准误杀率是 37.6%，3/3 全中的概率约 5.3% —— **属小样本的尾部，不能单独作为证据**。真正撑住结论的是 44.9 天的反事实（627 次触发、4 段全负）。
- **历史反事实用 tick 近似成交价**（触发后第一个 `bid ≤ 0.50` 的采样价），真实实盘有 1.5–3.7s 延迟，实际滑穿只会**更差**。
- **本文与引擎回测的一个分歧要如实标注**：仓库引擎在"严格 0.95 + 带 BTC 确认门"下给出"止损净 PnL 略好（−$99.59 → −$91.97）"，主要来自回撤下降，且差异在噪声内；**本文件的 44.9 天逐笔反事实与今日实盘都指向止损为负**。两者不冲突于"止损不创造期望"，只在"引擎默认门控是否附带择时价值"上有分歧。
- 历史数据的价格源仍是 CEX 度量（结算为 Chainlink 60s TWAP），这一错配风险对本结论同样适用。
