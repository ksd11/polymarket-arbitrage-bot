# cmm-v2 新策略回测报告

> 日期：2026-09-04
> 策略文件：`src/strategies/btc5m/conditional-market-maker-v2.ts`
> 回测框架：`src/backtest/btc-5m-backtest.ts`

## 一、背景与目标

原 `conditional-market-maker`（cmm）做市策略回测 ROI **-6.44%**（cycle win rate 27%），系统性亏损。数据挖掘发现：

- Polymarket BTC 5min 市场**近似有效定价**，纯对称做市无 alpha。
- 做市买入的平价腿（≥0.50）被系统性高估，到期归零拖累整体。
- **低价腿（≤0.55）有正期望，高价腿（≥0.55）负期望**。
- **DOWN 腿（赌跌）的低价买入有结构性正期望**——BTC 5min 存在"跌快涨慢"的不对称，市场对下跌概率系统性低估。

基于此，将策略从"做市"重构为"**早期低价腿 taker 买入 + 持有到到期**"，得到 `conditional-market-maker-v2`。

## 二、策略设计

核心逻辑（`buildBtc5mConditionalMarketMakerV2Quotes`）：

1. **低价腿择时买入**：仅当某条腿 ask 落在 `[minBidPrice, maxBidPrice]` 区间时买入。
2. **早期门槛**：`seconds_left >= minSecondsLeftToBuy` 才买（规避临近到期已快归零的腿）。
3. **只买 DOWN 腿**（`buyLegsOnly="DOWN"`）：DOWN 低价腿结构性更强，UP 低价腿拖累整体。
4. **方向过滤默认关闭**（`directionMinMomentumBps=999`）：逆势抄底 DOWN 恰恰是 alpha 来源。
5. **持有到到期**：赢返 1，输归零，不做中途对冲。

## 三、回测结果

### 3.1 数据源说明（重要）

| 文件 | 时间范围 | 类型 | 可用于回测 |
|------|---------|------|-----------|
| `btc5m-history-3days.csv` | 7/21~7/24 | 纯行情快照（sample 行，含 up_mid/down_mid） | ✅ 唯一可靠数据源 |
| `btc5m-history-3days02.csv` | 7/25~7/28 | 策略运行日志（decision 行，缺 mid/winner） | ❌ 字段错位，不可用 |
| `btc5m-history-3days03.csv` | 7/29~8/2 | 策略运行日志（同上） | ❌ 字段错位，不可用 |

**关键**：只有 `3days.csv` 是干净的行情快照，可做严谨回测。3days02/03 是 dry_run 策略日志（字段错位、缺 `up_mid`/`down_mid`/`winning_outcome`、行情非法），不能作为回测数据源。

### 3.2 样本内/样本外切分验证

将 `3days.csv`（859 cycle）按时间切分：
- **训练集**：7/21~7/23（约 666 cycle）
- **测试集**：7/24（约 193 cycle，留出验证）

### 3.3 参数扫描结果（训练集）

`DOWN` 腿 + 关闭方向过滤，扫描 `maxBidPrice`：

| maxBidPrice | DOWN ROI | BOTH ROI |
|-------------|----------|----------|
| 0.40 | -4.14% | -0.43% |
| 0.45 | -3.78% | -1.97% |
| 0.50 | -0.03% | -2.03% |
| 0.55 | **+1.43%** | -1.88% |
| 0.60 | +0.87% | -1.62% |

**结论**：DOWN 腿系统性优于 BOTH；最优 maxBid = 0.55。

### 3.4 样本外验证（测试集 7/24）

| maxBidPrice | DOWN ROI | BOTH ROI |
|-------------|----------|----------|
| 0.50 | **+6.83%** | +0.31% |
| 0.55 | **+6.94%** | -0.48% |
| 0.60 | +5.42% | -0.55% |

**结论**：DOWN 腿在留出测试集上依然稳健正收益（+6.83%~+6.94%），**alpha 可复现，非过拟合**。

> ⚠️ **本结论已在 30 天数据上被推翻（见第五节）。** 当时只有 3 天 859 cycle 数据，测试集仅 1 天 193 cycle，样本量太小，+6.94% 是小样本运气。

### 3.5 稳健性检验（3 天数据）

| 参数 | 影响 | 结论 |
|------|------|------|
| `minSecondsLeftToBuy`（30→180） | ROI +1.43% → +1.63% | 影响很小，非核心 alpha |
| `minBidPrice`（0.10→0.40） | ROI 几乎不变 | 极低价腿极少，无影响 |
| `directionMinMomentumBps`（3→999） | +2.58% → +2.68% | 影响极小（仅差 3 笔） |

核心 alpha 来自"**DOWN 腿 + maxBid≤0.55 低价买入**"这一简单规则，而非复杂的时间/价格/方向过滤。

## 四、30 天数据回测（2026-09-05 补充，关键修正）

### 4.1 数据源扩展

发现 `final-30-managed-live-20260802-190357.csv`（880M，278 万行）是 **8/2~9/4 共 33 天的真实行情**（`decision` 行含合法盘口 + `resolution` 行含明确 `winning_outcome`），是远超 3 天样本的可靠数据源。

预处理：提取精简字段 → 5 秒降采样 → `data/btc5m-history-30days-5s.csv`（57 万行，115M）。降采样已验证不影响结论（3days 降采样后仍 +2.75%）。

### 4.2 30 天完整回测（9546 cycle）

| 配置 | ROI | PnL | win rate |
|------|-----|-----|----------|
| DOWN, maxBid=0.55 | **+0.07%** | +$13.95 | 47.55% |
| UP, maxBid=0.55 | -2.40% | -$492.60 | - |
| BOTH, maxBid=0.55 | -1.17% | -$852.27 | - |

**核心结论**：
1. DOWN 腿**显著优于 UP 腿**（+0.07% vs -2.40%），方向性结论在大样本上依然成立。
2. 但 **DOWN 腿的绝对 alpha 基本消失**（+0.07% ≈ 0），远低于 3 天样本的 +2.68%。

### 4.3 按周分解（alpha 时间不稳定性）

| 周 | 时间段 | ROI | PnL |
|----|--------|-----|-----|
| W1 | 8/2~8/8 | +3.38% | +$152.15 |
| W2 | 8/9~8/15 | -1.12% | -$50.85 |
| W3 | 8/16~8/22 | -2.96% | -$127.10 |
| W4 | 8/23~8/29 | -0.29% | -$12.35 |
| W5 | 8/30~9/4 | +1.99% | +$62.10 |

**alpha 时有时无、波动剧烈（+3.38% ~ -2.96%），整体 30 天累计 +0.07%，本质是市场有效定价下的随机波动，不是可持续的 alpha。**

### 4.4 无偏结构统计（为什么没有 alpha）

对 30 天数据做"若在早期（seconds_left≥60）以价格 p 买入某腿并持有到结算"的无偏期望统计，**推翻了 3 天样本的核心假设**：

| 价格桶 (ask) | DOWN ROI | UP ROI |
|-------------|----------|--------|
| 0.20~0.30 | **-25.76%** | -6.79% |
| 0.30~0.40 | **-5.17%** | -3.35% |
| 0.40~0.50 | -1.23% | -3.36% |
| 0.50~0.60 | **+1.20%** | -2.84% |
| 0.60~0.70 | -1.85% | +0.31% |

**关键发现**：
1. 3 天样本的"低价腿正期望"结论是**错误的**——30 天大样本显示**极低价腿（0.20~0.40）反而是强负期望**（-5%~-26%），因为"低价"意味着市场强烈预期它输，且多数时候确实输。
2. 真正的微弱正期望在 **0.50~0.60 的平价附近**（DOWN +1.20%）。
3. UP 腿几乎所有价格桶都负期望，印证"DOWN 优于 UP"。

这说明 cmm-v2 默认的 `minBid=0.10` 买入区间太宽，把大量负期望的低价腿也买进来了，正负抵消后只剩 +0.07%。

### 4.5 收窄买入区间（最后一个优化尝试）

| 买入区间 | ROI |
|---------|-----|
| 0.10~0.55（原默认） | +0.07% |
| 0.45~0.55 | +0.13% |
| 0.48~0.55 | **+0.38%** |
| 0.50~0.55 | +0.29% |
| 0.50~0.58 | -0.18% |
| 0.50~0.60 | -0.31% |

收窄到 0.48~0.55 把 ROI 从 +0.07% 提到 +0.38%，但**仍很微弱**，且这是在 30 天数据上调参的结果，本身可能又是过拟合。**不值得据此实盘。**

## 五、最终对比（30 天，9546 cycle）

| 策略 | 30 天 ROI | 3 天 ROI | 结论 |
|------|-----------|----------|------|
| cmm（做市 baseline） | -6.44%（3天） | - | 明确负期望 |
| **cmm-v2（DOWN, maxBid=0.55）** | **+0.07%** | +2.68% | 30 天接近零，无稳健 alpha |

## 六、最终配置（已固化到默认参数）

```
--strategy conditional-market-maker-v2
--cmm-v2-buy-legs-only DOWN      # 默认 DOWN
--cmm-v2-max-bid-price 0.55      # 默认 0.55
--cmm-v2-min-bid-price 0.10      # 默认 0.10
--cmm-v2-min-seconds-left 60     # 默认 60
--cmm-direction-min-momentum-bps 999  # 默认关闭方向过滤
```

**开箱即用命令**：

```bash

npx tsx src/backtest/btc-5m-backtest.ts \
  --strategy conditional-market-maker-v2 \
  --csv data/btc5m-history-3days.csv

# 30 天数据
npx tsx src/backtest/btc-5m-backtest.ts \

  --csv data/btc5m-history-30days-5s.csv
```

## 六、风险提示

1. **样本有限**：仅 3 天（859 cycle）可用数据，测试集仅 1 天（193 cycle）。+6.94% 的测试集收益样本量偏小，需更多历史数据进一步验证。
2. **市场结构假设**：alpha 依赖"DOWN 腿被系统性低估"这一市场结构，若做市商/参与者行为变化，该结构可能消失。
3. **滑点与手续费未计入**：回测按 ask 立即成交（taker），未含 gas/手续费/滑点，实盘 ROI 会打折。
4. **单边持仓风险**：只买 DOWN 腿是单边敞口，BTC 连续上涨时会连续亏损（测试集 maxConsecutiveLosingCycles=6~8）。
